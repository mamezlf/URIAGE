# URIAGE

> フリマアプリ販売者向けの売上・利益管理アプリ

## 概要

URIAGE は、フリマアプリでハンドメイド作品を販売していた経験から生まれた iOS アプリです。

販売を続ける中で、

- 売上は分かるが実際の利益が分かりづらい
- 送料や梱包費を毎回計算するのが面倒

といった課題を感じていました。

そこで、商品ごとの売上・費用・利益を一元管理できるアプリとして URIAGE を開発しました。


---

## 課題

フリマアプリでは売上金額は表示されますが、

- 販売手数料
- 送料
- 梱包材費
- 仕入れ原価

などを考慮した実際の利益は分かりません。

特にハンドメイド作品は利益率が低いことも多く、

「結局いくら残ったのか」

を把握するために毎回計算が必要でした。

---

## 解決したこと

URIAGE では以下の情報を商品単位で管理できます。

- 商品名
- 販売価格
- 販売手数料
- 送料
- 梱包費
- 原価

これらをもとに利益を自動計算し、販売状況を一覧で確認できるようにしました。

---

## 主な機能

### 商品管理

- 商品の登録
- 編集
- 削除
- 一覧表示

### 利益計算

- 売上金額の管理
- 費用の管理
- 利益の自動計算

### 商品URLからの情報取得

商品URLを入力すると、

- 商品名
- 商品価格

を自動取得できます。

これにより手入力の負担を削減し、登録作業を効率化しました。

---

## 開発背景

最も大きな学びは、

「課題を発見する → 実際に作る → 自分で使う → 改善する」

というサイクルを経験できたことでした。

実装そのものよりも、実際にアプリを利用して課題が解決された瞬間に大きなやりがいを感じました。

また、利用中に

> 毎回商品情報をコピペするのが面倒

という新たな課題を発見し、商品URLから情報を取得する機能を追加しました。

この経験を通じて、ユーザーの課題を観察しながら継続的に改善するプロダクト開発の面白さを実感しました。
